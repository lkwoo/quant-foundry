# HAA-Balanced

Wouter Keller·Jan Willem Keuning의 [HAA 원문](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4346906)과
[공동저자의 규칙 설명](https://indexswingtrader.blogspot.com/2023/02/introducing-hybrid-asset-allocation-haa.html)에
따라 Global 8 / Top 4인 HAA-Balanced를 구현한다. 단일 종목 추세 전략과 별도로 포트폴리오를 평가한다.

```powershell
quantfoundry update-haa
quantfoundry -q haa
# 다른 QuantFoundry DB 또는 설정
quantfoundry update-haa --db D:/QuantData/quantfoundry.sqlite3
quantfoundry -q haa --db D:/QuantData/quantfoundry.sqlite3
quantfoundry -q haa --config config/settings.toml
```

## 규칙

| 역할 | ETF |
| --- | --- |
| 공격자산 | SPY, IWM, VEA, VWO, VNQ, DBC, IEF, TLT |
| 경기·물가 경보 자산 | TIP |
| 방어자산 | BIL, IEF |

`13612U = (1개월 수익률 + 3개월 수익률 + 6개월 수익률 + 12개월 수익률) / 4`.
월말 수익률은 `해당 월말 adj_close / n개월 전 월말 adj_close - 1`이다.
Yahoo의 배당·분할 조정종가로 총수익률을 근사한다. 원시 종가, 가중 모멘텀(13612W),
21/63/126/252 거래일 근사를 사용하지 않는다.

- TIP 모멘텀 ≤ 0: BIL과 IEF 중 모멘텀이 더 높은 하나에 100% 배분한다.
- TIP 모멘텀 > 0: 공격자산 모멘텀 상위 4개에 각각 25%를 배분한다.
  선택된 자산의 모멘텀 ≤ 0이면 그 25%를 최상위 방어자산으로 대체한다.
- IEF 자체 편입과 방어 대체 비중이 겹치면 합산한다.
- 두 방어자산이 모두 음수여도 더 높은 자산을 선택한다.
- 원전에서 정하지 않은 동률은 위 공격자산 나열 순서로 결정하고, 방어자산 동률은 BIL을 선택한다.

## 최신일과 월말 의사 결정

`-q haa`는 네트워크 요청이나 DB 변경 없이 저장된 가격을 읽는다.
기준일은 **HAA ETF 10개에 저장된 날짜의 최댓값**이다. 한국 주식 등 다른 자산의 최신일은 포함하지 않는다.
각 ETF의 최신일도 출력한다. 최신 시세 여부는 자동 보장하지 않으며 `update-haa`로 갱신한다.

원전은 미국 마지막 거래일 종가로 판단하고 다음 월말까지 보유하는 월간 전략이다.
`exchange_calendars`의 XNYS 캘린더로 휴일·주말을 반영한다. 현재 월 전체 예정 거래일을 확인하므로
단순히 DB에서 가장 늦은 행을 월말로 간주하지 않는다. NASDAQ/NYSE Arca ETF는 이 공통 미국 거래일을 사용한다.

- 기준일이 월말이면 확정된 월말 목표 비중과 리밸런싱 지침을 출력한다.
- 월중이면 최신 가격으로 계산한 **잠정 신호**와 **최근 월말의 보유 목표**를 함께 출력한다.
  잠정 신호는 현재 월 가격을 지난 1·3·6·12개월의 월말 가격과 비교한다.
  같은 일자로 1·3·6·12개월을 이동한 일간 롤링 신호가 아니다.
  원전대로라면 최근 월말 목표를 유지하고 다음 월말에 재평가한다.
- 실제 보유량·현금·체결가격은 입력받지 않으므로 목표 비중만 제공하며 매매 수량은 계산하지 않는다.
  종가 확인 후 실제 주문 시점의 가격은 달라질 수 있다.

최신일 및 필요한 과거 월말의 가격이 하나라도 없으면 해당 계산을 보류하고 종목·날짜를 출력한다.
앞 날짜로 채우거나 모든 종목이 있는 과거 날짜로 되돌아가지 않는다.
계산에 사용하지 않는 중간 거래일 누락은 월말 수익률 계산을 막지 않는다.
월중 잠정 신호는 가능하지만 최근 월말 목표를 계산할 수 없는 경우 두 상태를 구분한다.
판단이 불완전하면 종료 코드 1을 반환한다.

## 수집 및 저장

기존 FDR 주식 목록에는 이 ETF들이 없을 수 있어 고정된 10개 ETF를 `update-haa`로 수집한다.
기존 `update-all`은 주식 목록 기반이며 HAA ETF 전체 갱신을 대신하지 않는다.
HAA 사용 시 `update-haa`를 별도로 실행한다.

기존 설정의 DB·동시 처리 수·타임아웃·재시도를 재사용한다. 보관 시작일은 설정 날짜와
14개월 전 월초 중 더 오래된 날짜이며, 기존 ETF 가격이 더 오래되면 그 날짜부터 전체 재조회한다.
배당 조정에 따른 과거 가격 수정도 기존 가격 정정 처리로 반영한다.

`price`에 IEF/TLT는 NASDAQ, 나머지는 NYSEARCA로 저장한다.
`stock`의 전체 종목 목록을 교체하거나 ETF만으로 NASDAQ 목록을 덮어쓰지 않는다.
HAA는 `price`를 직접 사용하므로 이 수집 명령은 price_detail·RS를 계산하지 않는다.
기존 가격 정정으로 지표가 무효화된 경우 기존 갱신 명령에서 재계산한다.
현재 주식 목록이나 저장된 과거 RS 평가 대상에 포함되지 않는 ETF는 주식 RS를 무효화하지 않는다.
NYSEARCA 전체 종목 목록 조회는 지원하지 않으며 설정의 기본 갱신 시장에 추가하지 않는다.

명시적 데이터 없음은 `no_data`, 통신·검증·저장 실패는 `failed`에 기록하는 기존 정책을 유지한다.
수집 성공 코드만으로 HAA 판단 가능 여부가 보장되지는 않는다. 이어서 `-q haa`로 확인한다.

실제 수집과 조회에는 `python -m pip install -e ".[market-data]"`가 필요하다.
계산 테스트는 네트워크 없이 실행하며, 임계값·자산 대체·동률·월말 기준·미래 가격 배제·누락·읽기 전용 조회를 검증한다.
